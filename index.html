⚙ Admin

Paste a YouTube or Google Drive link and press Enter — the thumbnail appears below so you know which video is which. Grab and drag a row up/down to change sidebar order (⬆ ⬇ work too), 🙈 to hide one for a while (or right-click the thumbnail), 🗑 to delete. Everything saves instantly.

📁 Easiest: a video folder. Make a folder in Google Drive, share it Anyone with the link, and paste the folder’s link here. After that, anything you put in the folder lands in her list by itself — on your phone: Drive app → open the folder → + → Upload → pick as many as you like. Delete one from the folder and it leaves her list too. One folder for everything is fine: put the same link in the Pictures tab and the videos in it come here while the photos go to her slideshow.

🔑 Folders need a Google key — set it up once (free, about 3 minutes)
  1. Open console.cloud.google.com and make a project (call it Bea).
  2. APIs & Services → Library, search Google Drive API, press Enable.
  3. APIs & Services → Credentials → Create credentials → API key. Copy it.
  4. Recommended: press Edit API key. Under Application restrictions pick Websites and add your app’s address with /* on the end (like https://your-app.vercel.app/*) plus http://localhost:8420/*. Under API restrictions pick Google Drive API. Save.
  5. Paste the key here. It’s fine for it to travel with the app — it can only read things you’ve already shared with a link.
📲 Add YouTube videos straight from the YouTube app’s Share button (iPhone, set up once)
  1. Open the Shortcuts app and tap + to make a new shortcut. Name it Add to Bea.
  2. Open its settings (the ⓘ / the menu by its name) and turn on Show in Share Sheet.
  3. Add the action URL Encode (it should say “Encode Shortcut Input”).
  4. Add the action Open URLs. In its box type https://bea-coral.vercel.app/?add= and right after it, with no space, insert the URL Encoded Text variable.
  5. Done. Now in YouTube: Share → More → Add to Bea. The app opens, says Added, and the video is on every device. (Tip: in that share list press Edit Actions and add it to Favorites so it’s always at the top.)

Works for Google Drive video links shared from the Drive app too.

Other way: upload from inside this app (needs extra Google setup)

Upload straight off this phone’s camera roll. It goes into a Bea’s Play folder in your own Google Drive and lands in her list by itself. The video folder above does the same job with less setup.

First time on a new Google account? Set it up once ⚙
  1. Open console.cloud.google.com and make a project (call it Bea).
  2. APIs & Services → Library, search Google Drive API, press Enable.
  3. OAuth consent screen → External → put in a name and your own email → Save. Then add your own Gmail under Test users.
  4. Credentials → Create credentials → OAuth client ID → Web application.
  5. Under Authorized JavaScript origins add both the address you open this app at (the https:// one) and http://localhost:8420.
  6. Copy the Client ID it gives you and paste it here — it’s not a password, and it travels to your other devices by itself.
